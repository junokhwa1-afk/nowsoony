인쇄 창에서 대상 프린터를 ‘PDF로 저장’으로 선택하면 PDF 한 장으로 저장됩니다. (A4 가로 1장) 아래 ‘입력’ 영역에서 값을 바꾸면 보고서가 바로 갱신됩니다.

한 줄에 메뉴 하나씩 입력하면 자동 저장됩니다. 아래 메뉴는 예시이니 우리 급식소 메뉴로 수정하세요. 분류마다 6개 이상(직전 주 중복 회피까지 하려면 12개 이상) 권장합니다.

➕ 메뉴 추가
  1. 왼쪽 메뉴DB 관리에서 우리 급식소 메뉴를 분류별로 입력합니다. (한 줄에 하나)
  2. 왼쪽 식단 설정에서 시작일(월요일), 김치 종류, 주간·야간 근무자(최명자/김정진 중 선택) 등을 정하고 식단표 생성을 누릅니다.
  3. 결과는 식단표 결과 화면에 표시되며, 마음에 들지 않으면 다시 섞기를 누르세요.
  4. 결과의 칸을 클릭하면 직접 수정할 수 있고, 왼쪽 메뉴바의 인쇄(A4 가로 1페이지) 또는 엑셀로 저장(.xlsx)·PDF로 저장(.pdf)을 누르면 출력됩니다.
  5. 같은 주 안에서는 같은 분류 메뉴가 겹치지 않으며, 직전 주에 만든 메뉴도 가능한 한 피합니다.
  6. 메뉴DB는 이 브라우저에 저장됩니다. 다른 PC에서 쓰려면 .json으로 저장해 불러오세요.
👥 일자별 식수인원 입력
바탕은 흰색, 토·일요일과 휴무일(입력 없는 날)만 주황색으로 표시됩니다. 예) 마감 26일 기준 10월 = 9/26 ~ 10/25. 칸에 직접 입력하거나 엑셀 표를 복사해 붙여넣고, 파일(.xlsx/.csv)은 올려주신 ‘식당 인원수 파악’ 형식으로 불러옵니다. 일요일은 식단표에 없어 입력하지 않습니다(토요일은 휴일 색으로 표시되지만 입력은 가능).

왼쪽의 원본을 보면서 오른쪽 표에 메뉴를 입력·수정하세요. ‘자동 인식’은 인터넷이 연결되어 있을 때 글자를 읽어 표를 채우며(처음 한 번 1~2분 걸릴 수 있음), 인식 결과는 틀릴 수 있으니 반드시 확인하고 고쳐 주세요.
